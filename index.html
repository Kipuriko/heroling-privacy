English

Heroling (“the app”) is an offline habit tracker with RPG gamification. We designed it to work without collecting your personal data.

What we collect

Nothing is sent to us or to any third party. The app has no account system, no analytics, no advertising, and no third-party tracking SDKs.

Data stored on your device

All app data — your habits, hero, progress, settings — is stored locally on your device (in the app’s private storage). It never leaves your device except:

  • Cloud backup (optional, user-controlled): Android Auto Backup may copy the app’s local data to your own Google account’s backup, if backup is enabled in your system settings. This backup belongs to you, not to us; we cannot access it.
  • Save export (optional, user-initiated): you can export a save file to a location you choose. It goes only where you send it.
  • Crash report sharing (optional, user-initiated): if the app crashes, a diagnostic log (stack trace, app version, device model/OS) is stored locally. It is shared only if you tap “Share” in Settings, to a destination you pick.

Network use

The only network activity is optional: downloading the AI model file if you choose to. The app requests a file from the URL configured by the publisher over HTTPS. This is a download only — no personal data is uploaded.

Permissions

  • Internet — only to download the optional AI model file.
  • Notifications — local habit reminders you schedule.
  • Vibration — haptic feedback.

Children

The app is suitable for general audiences and does not knowingly collect data from anyone, including children.

Changes

We may update this policy; the “Last updated” date will change accordingly.

Русский

Heroling («приложение») — офлайн-трекер привычек с RPG-геймификацией. Приложение спроектировано так, чтобы работать без сбора ваших персональных данных.

Что мы собираем

Ничего не отправляется нам или третьим лицам. В приложении нет аккаунтов, аналитики, рекламы и сторонних трекинг-SDK.

Данные на вашем устройстве

Все данные приложения — привычки, герой, прогресс, настройки — хранятся локально на устройстве (в приватном хранилище приложения) и не покидают его, за исключением:

  • Облачный бэкап (опционально, по вашему выбору): Android Auto Backup может копировать локальные данные приложения в бэкап вашего аккаунта Google, если резервное копирование включено в системных настройках. Этот бэкап принадлежит вам, а не нам; мы не имеем к нему доступа.
  • Экспорт сейва (опционально, по вашей инициативе): вы можете выгрузить файл сохранения в выбранное вами место. Он попадает только туда, куда вы его отправите.
  • Отправка отчёта о сбое (опционально, по вашей инициативе): при падении приложения диагностический лог (стек, версия приложения, модель/ОС устройства) сохраняется локально. Он передаётся только если вы нажмёте «Поделиться» в настройках, в выбранное вами место.

Использование сети

Единственная сетевая активность — опциональная: докачка файла ИИ-модели, если вы этого захотите. Приложение запрашивает файл по HTTPS-ссылке, заданной издателем. Это только скачивание — никакие персональные данные не выгружаются.

Разрешения

  • Интернет — только для докачки опционального файла ИИ-модели.
  • Уведомления — локальные напоминания о привычках, которые вы настроили.
  • Вибрация — тактильная отдача.

Дети

Приложение подходит для широкой аудитории и не собирает данные ни у кого, включая детей.

Изменения

Мы можем обновлять эту политику; дата «Обновлено» будет меняться соответственно.
